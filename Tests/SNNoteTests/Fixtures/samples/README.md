# Device samples

The project owner contributed these Supernote N6 (Nomad) device samples, format 20260016, under the project's [MIT licence](../../../../LICENSE). The samples are anonymised. Generated content replaces the file and page identifiers, link targets, imported template, cover, handwritten stroke in the PDF mark, and two signature strokes in the dense-layer notebook.

- `epub-n6-20260016.mark` exercises a sparse EPUB annotation on document page 22 with a cleared drawing layer.
- `layers-dense-n6-20260016.note` exercises dense ink, layer stacking and a hidden layer with a stored bitmap.
- `pdf-highlights-n6-20260016.mark` holds a generated wave, two highlights and an underline with paired sheet and PDF coordinates.
- `picture-links-cover-n6-20260016.note` exercises an image cover, an imported template, a keyword, and links to a document and another page.
- `textbox-links-n6-20260016.note` exercises three Russian text boxes of different sizes, a heading, an internal page link and a web link.
